# 🎙️ 독거노인을 위한 음성 기반 AI SNS 플랫폼

## 📌 프로젝트 개요
고령층의 SNS 사용 빈도와 참여율이 낮고 접근에 어려움을 느끼는 문제를 해결하기 위해 기획된 **음성 기반 맞춤형 SNS 플랫폼**입니다. STT(음성 인식), TTS(음성 합성), 그리고 생성형 AI 기술을 활용하여 혼자 사는 어르신들이 쉽게 소통할 수 있는 커뮤니티를 제공합니다. 이를 통해 독거노인 간의 커뮤니케이션을 활성화하고 전반적인 생활 안전망을 구축하는 것을 목표로 합니다.

## 🎯 주요 타겟층
* 혼자 거주하시는 고령의 독거노인
* 텍스트 기반 기기 조작 및 SNS 사용에 어려움을 겪는 어르신
* 지속적인 소통과 정서적 케어가 필요한 노년층

## 💡 핵심 기능
* **음성 기반 손쉬운 정보 입력 (STT):** 키보드 타이핑이나 복잡한 터치 조작 없이, 목소리만으로 일상과 안부를 쉽게 입력할 수 있습니다.
* **AI 자동 게시물 작성 (OpenAI API):** 어르신이 말씀하신 내용을 AI가 인식하여 자연스럽고 따뜻한 문맥의 SNS 게시글로 자동 다듬어 게시합니다.
* **음성 피드백 및 소통 (TTS):** 타인의 게시물이나 안부 글을 화면의 텍스트로 읽을 필요 없이, AI 음성을 통해 들려주어 직관적인 소통 환경을 제공합니다.

## 🛠 활용 기술 스택 (Tech Stack)
* **Backend:** FastAPI, Python
* **Database:** SQLite
* **AI & API:** OpenAI API (텍스트 정제), STT (Speech-to-Text), TTS (Text-to-Speech)
* **Frontend:** HTML, JavaScript (단일 HTML 파일 기반)

## 📂 산출물 형태
* 복잡한 프론트엔드 프레임워크 없이 서버와 연동되어 즉각적인 시연이 가능한 **단일 HTML 파일** 기반의 경량 웹 어플리케이션입니다.
