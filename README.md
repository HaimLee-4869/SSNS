# 🎙️ SSNS: 음성으로 시작하는 고령층의 첫 AI 경험

> **쉬운 접근성 → 매일의 성공 경험 → AI 리터러시 향상 → 세대 간 디지털 격차 해소 + 커뮤니티 (+ 생활안전은 부가 효과)**

---

## 📌 프로젝트 핵심 개념

### 🔄 SSNS의 선순환 구조

```
어르신의 일상
    ↓
[음성 입력 - 쉬운 접근성]
어려운 키보드/터치 → 목소리만으로 AI 사용 시작
    ↓
[AI가 다듬어 매일 자동 게시]
"나도 AI를 쓸 줄 아는구나" - 매일 반복되는 성공 경험
    ↓
[타인에게 노출 & 상호작용]
• 가족과 같은 플랫폼에서 소통 (세대 간 대화 주제 생성)
• 비슷한 또래와의 댓글/응원
• 커뮤니티 확장
    ↓
[핵심 가치 창출]
1️⃣ AI 리터러시 향상: 매일 써보며 AI에 대한 두려움 해소, 활용 자신감 상승
2️⃣ 세대 간 디지털 격차 해소: 가족과 같은 방식으로 소통, 기술 소외감 완화
3️⃣ 개인 커뮤니티 형성: 일상으로 맺어진 따뜻한 관계망
    ＋ (부가 효과) 매일의 기록이 쌓이며 활동 패턴 기반 생활안전 신호로도 활용 가능
```

---

## 🎯 프로젝트 배경 및 목표

### 현실의 문제
- **AI/디지털 격차**: 고령층에게 AI는 낯설고 대단한 것으로 느껴져, 시도조차 하지 않는 경우가 많음
- **잘못된 활용 또는 무활용**: 어떻게 시작해야 할지 몰라 아예 사용하지 않거나, 필요한 만큼의 리터러시 없이 위험에 노출됨
- **세대 간 단절**: 자녀·손주 세대는 이미 AI/SNS를 일상적으로 쓰지만, 고령층은 같은 방식으로 소통하지 못해 대화가 줄어듦

### SSNS의 해결책
| 문제 | SSNS 솔루션 |
|------|----------|
| 🤖 **AI가 낯설고 어려움** | 🎙️ 음성으로 말하기만 하면 AI가 알아서 처리 (진입장벽 제거) |
| 📉 **디지털 격차로 인한 소외** | 📝 매일 자동으로 AI 결과물(SNS 게시물)을 받아보며 자연스럽게 리터러시 습득 |
| 👨‍👩‍👧 **세대 간 소통 단절** | 🫂 가족·또래와 같은 플랫폼에서 댓글/응원으로 자연스러운 상호작용 |
| ⚠️ **덤으로 걱정되는 안전** | 🚨 (부가 효과) 기록된 활동 패턴으로 이상 신호 시 알림 |

## 💡 핵심 가치 창출 메커니즘

### 1️⃣ **쉬운 접근성** → 어르신의 첫 AI 성공 경험

#### 음성 기반 입력 (STT)
```
어르신: "오늘 아침 따뜻한 국 먹고, 손주 영상통화 했어"
         ↓ [음성 인식 + AI 정제]
게시물: "오늘 아침은 정성 가득한 국 한 그릇! 
        손주와 영상통화로 하루를 밝게 시작했어요. 
        모두의 안부는 어떠세요? ☀️"
```

- **0️⃣ 터치 복잡성 제거**: 키보드 없음, 음성만으로 완성
- **🎯 AI를 처음 체험**: "내가 말한 걸 AI가 알아서 다듬어주는구나" 하는 성공 경험
- **⚡ 즉시 결과 확인**: 어르신은 "올렸어"만 하면 끝, 그 결과를 바로 확인

---

### 2️⃣ **매일 반복되는 경험** → AI 리터러시 습득 → 디지털 격차 해소

#### 반복 사용이 만드는 리터러시

**기존에는:**
```
AI/SNS는 어렵고 낯선 것 → 시도조차 안 함 → 격차 지속
```

**SSNS로 매일 사용하면:**
```
어르신의 일상
    ↓ [매일 매일 AI와 상호작용]
"오늘도 AI가 내 말을 잘 정리해줬네" → AI에 대한 두려움 감소
    ↓
손자딸 보기 → "할머니, 오늘도 SNS 하셨네!" (댓글/좋아요)
이웃 보기 → "저도 이렇게 AI 써볼래요" (또래 확산)
    ↓
**AI 리터러시 + 디지털 격차 해소가 자연스럽게 진행**
- AI를 "어려운 것"이 아니라 "말만 하면 되는 도구"로 체득
- 가족과 같은 플랫폼/방식으로 소통하며 세대 간 거리 좁힘
- 비슷한 또래와의 자연스러운 관계 형성
```

#### 댓글을 통한 상호작용 (TTS)
```
손주: "할머니 화이팅! 내일도 건강하세요!" (댓글)
       ↓ [TTS로 음성 변환]
어르신: 화면을 터치하지 않아도 음성으로 들음
       → 자동으로 응답 음성 녹음 가능
```

---

### ➕ 부가 효과: 매일의 기록이 만드는 생활안전 신호

핵심 목표는 어디까지나 **AI 리터러시 향상과 디지털 격차 해소**지만, 매일 꾸준히 쌓이는 기록은 부수적으로 활동 신호로도 쓰일 수 있습니다.

```
📊 정상적인 활동 패턴
Day 1~5: 매일 활동 기록 ✅ → [정상 상태 유지]

⚠️ 비정상 패턴 감지
Day 6~8: 기록 없음 → [경고 발생]
   ├─ 보호자에게 알림
   └─ 어르신에게 "안부 확인" 음성 전화
```

| 감시 항목 | 기준 | 조치 |
|----------|------|------|
| **일일 활동 여부** | 1일 1회 이상 기록 | 3일 미기록 → 알림 발송 |
| **사회활동** | "손주 만났다", "산책" 등 | 고립 신호 감지 → 상담 제안 |

## 🛠 기술 구현

### 시스템 아키텍처

```
┌──────────────────────────────────────────────┐
│      어르신 (일상 기록자)                    │
│   스마트폰/태블릿 웹브라우저                 │
│   - 음성 입력 (STT)                         │
│   - AI 정제된 게시물 확인                   │
│   - 댓글 음성 청취 (TTS)                    │
└────────────┬─────────────────────────────────┘
             │
             ↓ (매일의 일상 기록 전송)
             
┌──────────────────────────────────────────────┐
│      FastAPI 백엔드 서버                     │
├──────────────────────────────────────────────┤
│ 1. STT 처리                                  │
│    - 음성 파일 → 텍스트 변환               │
│                                             │
│ 2. AI 텍스트 정제 (OpenAI API)            │
│    - 자연스럽고 따뜻한 표현으로 변환      │
│    - 오타/비속어 자동 수정                │
│                                             │
│ 3. 자동 게시                                 │
│    - 정제된 텍스트 → SNS 게시물로 발행    │
│                                             │
│ 4. 패턴 분석 엔진 (부가 기능)              │
│    - 매일의 기록 수집 및 분석              │
│    - 활동 패턴 추출 / 비정상 탐지          │
│                                             │
│ 5. 알림 시스템 (추후)                       │
│    - 보호자에게 실시간 알림                │
│    - 복지기관 연동                         │
│                                             │
│ 6. TTS 음성 생성                            │
│    - 댓글 → 어르신이 들을 수 있는 음성    │
└────────────┬─────────────────────────────────┘
             │
             ↓
┌──────────────────────────────────────────────┐
│      SQLite 데이터베이스                    │
├──────────────────────────────────────────────┤
│ • 사용자 프로필 & 보호자 정보              │
│ • 매일의 음성/게시물 기록                  │
│ • 활동 패턴 분석 데이터                    │
│ • 커뮤니티 댓글/상호작용 로그              │
│ • 비정상 탐지 이력                        │
└──────────────────────────────────────────────┘
```

### 기술 스택

| 계층 | 기술 | 역할 |
|------|------|------|
| **Backend** | FastAPI, Python | 핵심 비즈니스 로직 |
| **Database** | SQLite | 경량 데이터 저장 |
| **AI/API** | OpenAI API | 텍스트 정제/톤 조정 |
| **음성처리** | STT / TTS API | 음성 ↔ 텍스트 변환 |
| **Frontend** | HTML5, JavaScript | 단일 파일 웹앱 |

## 📂 주요 특징

### ✨ 어르신 입장에서의 경험

**기존 SNS/AI 사용:**
```
어르신이 원하는 것: "나도 AI, SNS 좀 써보고 싶은데..."
어려운 과정: 복잡한 앱 → 로그인 → 텍스트 입력 
                    → 오타 수정 → 게시 → 중단
현실: 시도조차 안 함 → 디지털 격차 지속
```

**SSNS 사용:**
```
어르신이 원하는 것: "나도 AI, SNS 좀 써보고 싶은데..."
간단한 과정: [녹음] → [AI가 자동 정제] → [자동 게시] 
효과: 매일 성공 경험 → AI 리터러시 향상 → 세대 간 소통 → 따뜻함
```

### 🫂 커뮤니티 자동 형성

**매일 기록되는 일상이 관계의 물꼬를 튼다:**

```
어르신 A: "손자 영상통화했어요" ← 매일 기록
어르신 B: "우리 손자도 요즘 통화 자주해" ← 댓글
          ↓
손자들: "할머니들 친한 거 재미있다" ← 세대 간 상호작용
```

## 🚀 시작하기 (Getting Started)

### 1. 환경 설정 및 설치

```bash
# 저장소 클론
git clone https://github.com/HaimLee-4869/SSNS.git
cd SSNS

# Python 패키지 설치
pip install -r requirements.txt
```

### 2. 환경 변수 설정

`.env` 파일 생성:

```env
OPENAI_API_KEY=your_openai_api_key_here
DATABASE_PATH=./ssns.db
HOST=0.0.0.0
PORT=8000
```

### 3. 서버 시작

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 4. 웹브라우저에서 접속

```
http://localhost:8000
```

## 📊 예상 효과

### AI 리터러시 향상
- **성공 경험의 반복**: 말만 하면 AI가 결과를 만들어주는 경험을 매일 반복
- **두려움 해소**: "AI는 어렵다"는 인식에서 "나도 쓸 수 있다"는 자신감으로 전환
- **자연스러운 학습**: 별도의 교육 없이 사용 자체가 리터러시 습득 과정이 됨

### 세대 간 디지털 격차 해소
- **같은 플랫폼에서의 소통**: 가족·손주와 동일한 방식(SNS)으로 대화 주제 생성
- **자연스러운 관계**: 일상 기록을 통한 공감과 댓글
- **정서적 안정**: 매일 응원과 따뜻한 말씀 받음

### 개인 커뮤니티 확장
- **또래 확산**: 비슷한 상황의 어르신들 간 자연스러운 관계 형성

### (부가 효과) 생활안전
- **활동 기반 모니터링**: 매일 기록이 곧 활동 신호가 되어 이상 감지에 활용 가능
- **선제적 대응**: 비정상 감지 시 보호자에게 알림
