# 🎙️ SSNS: 음성으로 시작하는 고령층의 디지털 일상

> **접근성 → 매일 기록 → 사회적 노출 → 고독사 예방 + 커뮤니티 + 생활안전**

---

## 📌 프로젝트 핵심 개념

### 🔄 SSNS의 선순환 구조

```
어르신의 일상
    ↓
[음성 입력 - 쉬운 접근성]
어려운 키보드/터치 → 목소리만으로 입력
    ↓
[매일 자동 기록]
SNS에 일상이 매일매일 남겨짐
(정제된 글 자동 게시)
    ↓
[타인에게 노출 & 상호작용]
• 비슷한 또래와의 댓글/응원
• 가족과의 일상 공유
• 커뮤니티 확장
    ↓
[3가지 가치 창출]
1️⃣ 고독사 예방: 매일 활동이 기록되고 타인이 지켜봄
2️⃣ 개인 커뮤니티: 일상으로 맺어진 따뜻한 관계망
3️⃣ 생활안전 서비스: 기록된 패턴 → 비정상 감지 → 자동 알림
```

---

## 🎯 프로젝트 배경 및 목표

### 현실의 문제
- **접근성 장벽**: 독거노인의 높은 스마트폰 비활용률 (복잡한 앱, 텍스트 입력)
- **사회적 고립**: SNS조차 하지 않으면 누구도 일상을 모름
- **고독사 위험**: 혼자 있다가 발견되지 않는 최악의 상황

### SSNS의 해결책
| 문제 | SSNS 솔루션 |
|------|----------|
| 📱 **입력이 어려움** | 🎙️ 음성만 입력 (STT 자동 변환) |
| 💬 **기록이 없음** | 📝 매일 자동으로 SNS에 기록됨 |
| 👥 **고립됨** | 🫂 타인의 댓글/응원으로 자연스러운 상호작용 |
| ⚠️ **누가 모니터링?** | 🚨 기록된 활동 패턴 → 비정상 감지 → 자동 알림 |

---

## 💡 3단계 가치 창출 메커니즘

### 1️⃣ **쉬운 접근성** → SNS 사용률 증가

#### 음성 기반 입력 (STT)
```
어르신: "오늘 아침 따뜻한 국 먹고, 손주 영상통화 했어"
         ↓ [음성 인식 + AI 정제]
게시물: "오늘 아침은 정성 가득한 국 한 그릇! 
        손주와 영상통화로 하루를 밝게 시작했어요. 
        모두의 안부는 어떠세요? ☀️"
```

- **0️⃣ 터치 복잡성**: 키보드 없음, 음성만으로 완성
- **🎯 자동 정제**: AI가 자연스럽고 따뜻한 문맥으로 변환
- **⚡ 즉시 게시**: 어르신은 "올렸어"만 하면 끝

---

### 2️⃣ **매일 기록** → 타인에게 노출 → 커뮤니티 확장

#### 자동 일상 기록의 힘

**기록이 없을 때:**
```
독거노인 → 아무도 모름 → 고립
```

**SSNS로 매일 기록될 때:**
```
어르신의 일상
    ↓ [매일 매일 SNS에 기록]
손자딸 보기 → "할머니, 오늘도 활동하셨네!" (댓글/좋아요)
이웃 보기 → "우리 할머니와 비슷한 나이네!" (친구 신청)
요양사 보기 → "어르신 활동이 정상이시네" (모니터링)
    ↓
**개인 커뮤니티 자동 형성**
- 가족과의 따뜻한 일상 공유
- 비슷한 또래와의 자연스러운 관계 형성
- 정서적 고립 해소
```

#### 댓글을 통한 상호작용 (TTS)
```
손주: "할머니 화이팅! 내일도 건강하세요!" (댓글)
       ↓ [TTS로 음성 변환]
어르신: 화면을 터치하지 않아도 음성으로 들음
       → 자동으로 응답 음성 녹음 가능
```

---

### 3️⃣ **기록된 일상** → 생활안전 서비스 자동 제공

#### 활동 패턴 분석 시스템

**어르신의 일상 기록이 곧 생명 신호:**

```
📊 정상적인 활동 패턴
Day 1: "아침 산책 다녀왔어요" ✅
Day 2: "오늘은 손주와 통화했어" ✅
Day 3: "요즘 날씨가 참 좋네" ✅
...
→ [정상 상태 유지] ✅

⚠️ 비정상 패턴 감지
Day 1~5: 매일 활동 기록 ✅
Day 6: 기록 없음
Day 7: 기록 없음
Day 8: 기록 없음 
→ [경고 발생] 
   ├─ 보호자에게 즉시 알림
   ├─ 관할 복지센터에 알림
   └─ 어르신에게 "안부 확인" 음성 전화
```

#### 생활안전 모니터링 항목

| 감시 항목 | 기준 | 조치 |
|----------|------|------|
| **일일 활동 여부** | 1일 1회 이상 기록 | 3일 미기록 → 알림 발송 |
| **수면 패턴** | 게시물 시간대 분석 | 밤새 활동 → 건강 알림 |
| **식사 언급** | "밥 먹고", "국 마시고" 등 | 일주일 식사 기록 없음 → 영양 알림 |
| **사회활동** | "손주 만났다", "산책" 등 | 고립 신호 감지 → 상담 제안 |
| **응급 신호** | 비정상적 게시물 표현 | 부정적 표현 증가 → 정신 건강 체크 |

## 🛠 기술 구현

### 시스템 아키텍처

```
┌──────────────────────────────────────────────┐
│      어르신 (일상 기록자)                    │
│   스마트폰/태블릿 웹브라우저                 │
│   - 음성 입력 (STT)                         │
│   - AI 정제된 게시물 확인                   │
│   - 댓글 음성 청취 (TTS)                    │
└────────────┬─────────────────────────────────┘
             │
             ↓ (매일의 일상 기록 전송)
             
┌──────────────────────────────────────────────┐
│      FastAPI 백엔드 서버                     │
├──────────────────────────────────────────────┤
│ 1. STT 처리                                  │
│    - 음성 파일 → 텍스트 변환               │
│                                             │
│ 2. AI 텍스트 정제 (OpenAI API)            │
│    - 자연스럽고 따뜻한 표현으로 변환      │
│    - 오타/비속어 자동 수정                │
│                                             │
│ 3. 자동 게시                                 │
│    - 정제된 텍스트 → SNS 게시물로 발행    │
│                                             │
│ 4. 패턴 분석 엔진                           │
│    - 매일의 기록 수집 및 분석              │
│    - 활동 패턴 추출                        │
│    - 비정상 탐지 로직                      │
│                                             │
│ 5. 알림 시스템                              │
│    - 보호자에게 실시간 알림 (추후)        │
│    - 복지기관 연동 (추후)                  │
│                                             │
│ 6. TTS 음성 생성                            │
│    - 댓글 → 어르신이 들을 수 있는 음성    │
└────────────┬─────────────────────────────────┘
             │
             ↓
┌──────────────────────────────────────────────┐
│      SQLite 데이터베이스                    │
├──────────────────────────────────────────────┤
│ • 사용자 프로필 & 보호자 정보              │
│ • 매일의 음성/게시물 기록                  │
│ • 활동 패턴 분석 데이터                    │
│ • 커뮤니티 댓글/상호작용 로그              │
│ • 비정상 탐지 이력                        │
└──────────────────────────────────────────────┘
```

### 기술 스택

| 계층 | 기술 | 역할 |
|------|------|------|
| **Backend** | FastAPI, Python | 핵심 비즈니스 로직 |
| **Database** | SQLite | 경량 데이터 저장 |
| **AI/API** | OpenAI API | 텍스트 정제/톤 조정 |
| **음성처리** | STT / TTS API | 음성 ↔ 텍스트 변환 |
| **Frontend** | HTML5, JavaScript | 단일 파일 웹앱 |

## 📂 주요 특징

### ✨ 어르신 입장에서의 경험

**기존 SNS 사용:**
```
어르신이 원하는 것: "내 일상을 누군가 봐줬으면..."
어려운 과정: 복잡한 앱 → 로그인 → 텍스트 입력 
                    → 오타 수정 → 게시 → 중단
현실: 사용 중단 → 고립
```

**SSNS 사용:**
```
어르신이 원하는 것: "내 일상을 누군가 봐줬으면..."
간단한 과정: [녹음] → [자동 정제] → [자동 게시] 
효과: 매일 기록 → 타인이 봐줌 → 상호작용 → 따뜻함
```

### 🫂 커뮤니티 자동 형성

**매일 기록되는 일상이 관계의 물꼬를 튼다:**

```
어르신 A: "손자 영상통화했어요" ← 매일 기록
어르신 B: "우리 손자도 요즘 통화 자주해" ← 댓글
          ↓
손자들: "할머니들 친한 거 재미있다" ← 세대 간 상호작용
```

## 🚀 시작하기 (Getting Started)

### 1. 환경 설정 및 설치

```bash
# 저장소 클론
git clone https://github.com/HaimLee-4869/SSNS.git
cd SSNS

# Python 패키지 설치
pip install fastapi uvicorn openai python-dotenv
```

### 2. 환경 변수 설정

`.env` 파일 생성:

```env
OPENAI_API_KEY=your_openai_api_key_here
DATABASE_PATH=./ssns.db
HOST=0.0.0.0
PORT=8000
```

### 3. 서버 시작

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 4. 웹브라우저에서 접속

```
http://localhost:8000
```

## 📊 예상 효과

### 고독사 예방
- **기록의 힘**: "오늘도 활동했구나" → 타인이 알아차림
- **조기 신호**: 3일 이상 활동 없음 → 즉시 알림 → 신속한 대응
- **심리적 위안**: "누군가 내 일상을 보고 있다" → 고독감 감소

### 개인 커뮤니티 확장
- **자연스러운 관계**: 일상 기록을 통한 공감과 댓글
- **세대 간 연결**: 손주, 가족, 이웃과의 따뜻한 상호작용
- **정서적 안정**: 매일 응원과 따뜻한 말씀 받음

### 생활안전 서비스
- **데이터 기반 모니터링**: 기록된 패턴 → 정량적 분석
- **선제적 대응**: 비정상 감지 전 → 미리 알림 및 조치
- **개인화된 케어**: 개개인의 활동 패턴에 맞는 맞춤형 관심
